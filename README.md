# NOIR — практическая работа (React + JSX)

React-версия макета NOIR с клиентской маршрутизацией по примеру `project426`.

## Запуск

```bash
pnpm install
pnpm dev
```

## Страницы

- `/` — главная;
- `/catalog` — каталог;
- `/product` — карточка товара;
- `/cart` — корзина;
- остальные адреса показывают страницу 404.

`BrowserRouter` подключён в `src/main.jsx`. Пути и таблица маршрутов находятся в `src/routing/routing.jsx`. Для переходов между страницами используется `Link` из `react-router`.
